**3. Объем тестирования** 

| **Компонент**         | **Тестируемые аспекты**                                                                 |
|------------------------|----------------------------------------------------------------------------------------|
| **Функциональность**   | - Форма обратной связи доступна и интерактивна<br>- Все поля формы принимают ввод<br>- Кнопка отправки активна после заполнения обязательных полей<br>- Данные отправляются при нажатии на кнопку<br>- Отображаются корректные сообщения: об успехе или ошибках валидации |
| **Навигация**          | - Клик по логотипу ведёт на главную страницу https://21-school.ru/<br>- Все ссылки в шапке и футере кликабельны и ведут на существующие страницы |
| **Контент**            | - Текст не дублируется (на странице встречается повтор фразы — ожидаемо или ошибка?)<br>- Отсутствуют орфографические и пунктуационные ошибки<br>- Все изображения загружаются корректно |
| **Адаптивность**       | - Страница корректно отображается на мобильных устройствах, планшетах, ПК<br>- Нет горизонтального скролла<br>- Элементы не наезжают друг на друга |
| **Кроссбраузерность**  | - Страница и форма корректно работают в Google Chrome, Opera, Яндекс.Браузер (последние версии) |
| **Производительность** | - Страница загружается за приемлемое время (<3 сек)<br>- В консоли браузера нет ошибок (404, JS-ошибок) |                                                                  |

**Нетестируемые компоненты:** 

На этапе составления плана тестирования таких функциональных компонентов определено не было.

**5. Стратегия тестирования**

- **Функциональное тестирование**

- Smoke

- Регрессионное

- Тестирование формТестирование API

- **Нефункциональное (техническое) тестирование**

- Тест производительности

- Нагрузочное тестирование

- Стресс-тесты

- Тестирование работоспособности при больших объемах данных 

**6. Критерии начала тестирования**

- Тестовая среда разверпнута и доступна

- Тест-кейсы подготовлены и проверены

- Тест команда укомплектована

- Утвержден график тестирования 

**7. Критерии завершения тестирования**

- 100% выполнение тест-кейсов, включая критические сценарии

- Система стабильна (smoke-тест пройден, нет падений)

- Отчет о тестировании сформирован и утвержден

- Актуальные тест-кейсы и баги занесены в систему управления тестированием

- Сформирован итоговый отчет и получено согласие команды/заказчика
